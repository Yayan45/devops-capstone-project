# DevOps Capstone Project

This project is a Customer Accounts microservice.

## Features

* Create customer account
* Read customer account
* Update customer account
* Delete customer account
* List all accounts

## Purpose

This repository is used for planning and managing DevOps tasks using GitHub Issues and Kanban board.
